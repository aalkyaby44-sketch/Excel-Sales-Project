\# Interactive Sales \& Financial Dashboard | Excel



\## 📊 Project Overview

This project is an interactive business intelligence and sales performance dashboard built using advanced Microsoft Excel techniques. It helps stakeholders analyze sales, profits, and regional performance dynamically.



\## 🛠️ Tools \& Techniques Used

\* \*\*Microsoft Excel\*\*

\* \*\*Data Modeling \& Relationships\*\*

\* \*\*Pivot Tables \& Pivot Charts\*\*

\* \*\*Advanced Formulas \& Calculations\*\*

\* \*\*Conditional Formatting \& Dark Mode UI/UX Design\*\*



\## 📈 Key Dashboard Features

\* \*\*Sales by Category \& Sub-Category Analysis\*\*

\* \*\*Top 10 Cities and States Performance Metrics\*\*

\* \*\*Regional \& Sales Representative Breakdown\*\*

\* \*\*Year-over-Year (YoY) Sales and Quantity Trends\*\*
